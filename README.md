# Outlook PST 一括復旧ツール（ブラウザー版）

Windows 10/11 のクラシック版 Outlook で、PST ファイルの保存場所を確認し、OneDrive 配下などにある PST を安全にバックアップ・確認するための **インストール不要のポータブルアプリ**です。

## 利用者側で必要なもの

- Windows x64 PC
- ダウンロードした `OutlookPSTRecovery.exe` のみ
- .NET、ブラウザー拡張、追加ソフトのインストールは不要です

EXEを起動すると、PC内だけで動くローカルWebサーバーを開始し、既定のブラウザーで操作画面を開きます。通信先はこのPCの `127.0.0.1` です。PSTファイルを外部サーバーへアップロードしません。終了するときは起動したEXEを終了してください。

## 使い方

1. `OutlookPSTRecovery.exe` を起動します。
2. ブラウザーで **「PSTを検索」** をクリックします。
3. 検索結果で、ファイルの場所、サイズ、更新日時、OneDrive配下かどうかを確認します。
4. 必要に応じて **「元のフォルダーを開く」** でエクスプローラーから実ファイルを確認します。
5. PSTのバックアップを作成する場合は、クラシック版 Outlook を通常の方法で終了し、タスクマネージャーで `OUTLOOK.EXE` が終了したことを確認してから **「バックアップを作成・検証」** を実行します。バックアップ後にSHA-256を照合します。
6. 保存先が過去に記録されていれば候補として表示します。保存先が不明な場合は **「保存先フォルダーを選択」** で利用者が指定します。
7. 保存先をエクスプローラーで開き、バックアップと対象を確認したうえで、利用者自身がエクスプローラーでファイルを移動してください。本ツールはPSTを自動移動せず、Outlookプロファイルも変更しません。

## 保存先と履歴

- バックアップ：`%LOCALAPPDATA%\OutlookPSTRecovery\Backups`
- 保存先履歴：`%LOCALAPPDATA%\OutlookPSTRecovery\destination-history.json`

保存先履歴はこのPCのユーザープロファイル内に保存します。履歴がない場合、OneDrive配下にあるという理由だけで元の保存場所を推測しません。Outlook側の設定や既存の構成によっては、過去の保存先を特定できないことがあります。

## 安全上の注意・制限

- 元のPSTファイルは削除・上書きしません。
- オンラインのみのファイル（端末に実体がない可能性のあるファイル）はバックアップしません。エクスプローラーで対象ファイルを右クリックし、［このデバイス上で常に保持する］を選んでダウンロードを完了してから、再度検索してください。
- SHA-256の一致はコピー内容が一致したことを示しますが、PST内部の破損がないことまでは保証しません。
- 検索対象は主にユーザーフォルダー、ドキュメント、OneDrive、Outlookの既知の保存場所です。すべてのドライブやクラウド上だけに存在するファイルを網羅するものではありません。アクセス拒否されたフォルダーはスキップする場合があります。
- 保存先履歴は本ツールで利用者が記録した内容に限られます。記録がなければ、保存先を利用者が選択してください。
- PSTを移動した後は、Outlookのデータファイル設定やPOPアカウントの配信先を手動で確認してください。送受信と過去メールの表示が確認できるまでは、元のPSTを削除しないでください。
- このツールはPST内部の修復やOutlookプロファイルの完全な自動復旧を行うものではありません。

## EXEの入手方法

GitHubリポジトリの [Actions](https://github.com/noname2007jp/OutlookPSTRecovery/actions) を開き、**Build Outlook PST Recovery** の実行結果を選択します。ビルドが成功していれば、Artifacts から `OutlookPSTRecovery-Web-win-x64` をダウンロードします。ZIPを展開してEXEを起動してください。インストール作業は不要です。

## 開発情報

ブラウザー版は `OutlookPSTRecovery.Web` プロジェクトです。旧WinForms版のソースは `OutlookPSTRecovery` に残しています。
